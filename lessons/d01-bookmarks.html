Add the First Circle bookmarks to Chrome

Do this in Google Chrome, signed in with your work email. About 5 minutes.

Part 1: Download the file

1Click the button. The file saves to your Downloads folder. You stay on this page.
⬇ Download Bookmarks.html
If Chrome asks to keep the file, click Keep. Don't double-click the file to open it.

Part 2: Import it into Chrome

1Click the three dots at the top right of Chrome.
2Click Bookmarks and lists.
3Click Import bookmarks and settings…
4In the box, choose Bookmarks HTML File from the drop-down.
5Click Choose File.
6Click Downloads in the left sidebar.
7Click Bookmarks.html, then click Open.
8Click Done. Leave Show bookmarks bar switched on.
Your First Circle links now show in a row under the address bar. Click one to check it opens. If you had bookmarks before, the new ones are in a folder called Imported.
